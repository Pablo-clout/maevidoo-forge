# Export sketch (optional)

After Scrum PASS, if `memory-bridge` is enabled and an external store is configured by the human:

```text
Title: forge/<task-id> <YYYY-MM-DD>
Body (≤80 lines):
- Goal (1 line)
- Status: done | blocked
- Decisions (bullets from task notes)
- Next: path from _next-task-prompt.md
- Artefacts: key handoff/review paths only
```

Do not export full diffs, secrets, or entire pack prose.
