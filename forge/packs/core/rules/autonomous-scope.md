# Rule: autonomous scope

Long-session / pilot Code work without inventing parallel process.

## Non-negotiables
- Active `task.md` DoD is scope  
- Minimal diff  
- Every gate the DoD names is green — or the blocker is written in task `notes.md`  
- Handoffs + memory updated  
- No silent `catch` / swallowed errors (`forge/packs/core/personas/review-checklist.md`)  
- Local commit only when orchestrator says so; **never** push unless human asks  

## Anti-loop
An approach that failed twice is dead — attack from a different angle. Third dead end: stop and hand the question to the human.
